# Jogos

## Ache o erro
Usa a cena industrial e seis áreas clicáveis sem marcadores visíveis. Um clique fora do risco conta como tentativa errada e desconta pontos.

## Organize e cuide
Usa o tabuleiro visual de cuidados do posto. O operador seleciona um item e move para `A fazer`, `Em cuidado` ou `Posto pronto`, completando três cuidados para concluir.

A lógica de partida, pontuação, cronômetro e persistência está no `client/src/App.tsx`.
