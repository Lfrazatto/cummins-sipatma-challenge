# Conteúdo editável do SIPATMA

As perguntas oficiais ficam em `client/src/App.tsx`, no bloco `questionBank`, porque este projeto mantém o jogo em um único shell React. Para editar sem procurar pelo arquivo inteiro, use os marcadores de categoria:

- `Segurança`: perguntas 1–15, exclusivas do Quiz de Segurança.
- `Meio ambiente`: perguntas 16–30, exclusivas do desafio Cuide do ambiente.

Cada tema tem exatamente 15 perguntas e mistura múltipla escolha e verdadeiro/falso. Não reutilize a mesma pergunta entre os dois temas.

Os textos da interface devem falar de cuidado, prevenção, respeito, atenção, proteção das pessoas e do ambiente. Não incluir Lean, Kaizen, Kanban ou 5S no conteúdo do participante.
